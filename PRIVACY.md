# Privacy Policy for ShortsLock

ShortsLock does not collect, store, transmit, or share any personal data.

## Data Collection
- No user data is collected
- No browsing history is stored
- No analytics or tracking are used
- No external servers are contacted

## Local Processing
All functionality runs entirely within the user's browser using Chrome Extension APIs.
State (lock/unlock mode) is stored locally using Chrome's storage API.

## Permissions
ShortsLock requires limited permissions solely to:
- Detect YouTube navigation
- Redirect Shorts URLs to the Watch page
- Manage temporary unlock timers

These permissions are not used for any other purpose.

## Third Parties
ShortsLock does not use third-party services, SDKs, or scripts.

## Contact
If you have questions about this policy, you can contact the developer via GitHub.
